## 我们如何使用

1. **先讨论，再动手。** 从原曲的特点、歌词、情感和演唱者出发，寻找这首歌自己的处理方式。
2. **把好听的原因说清楚。** 不只记录 Style，还记录前奏、间奏、尾奏、各段唱腔和情绪变化的设计。
3. **试听之后再记录结论。** 区分「设计意图」「用户听后确认的效果」与「还需实验的猜想」。
4. **跨歌曲复用审美经验，不复制编曲配方。** 不强制高音、强混、大鼓、特定乐器或统一参数。
5. **增量维护。** 新发现更新共识，新歌增加案例；保留旧结论和重要修订线索。
