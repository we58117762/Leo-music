# Leo Music

这里记录 Leo 与 ChatGPT 在 Suno 翻唱探索中逐渐形成的音乐审美、有效提示词和试听发现。

**它是一份持续生长的创作笔记，不是流水线生成规则，也不是 Suno Skill。**

## 从这里开始

- [音乐创作共识](音乐创作共识.md)：长期偏好、协作方式、已验证的创作原则。
- [《大火》](案例/大火.md)：从压抑到释然的演唱与编曲设计。
- [《人是_》](案例/人是_.md)：宇宙的辽阔、人的渺小与希望。
- [《送情郎》](案例/送情郎.md)：民谣与传统小调交织，笑着告别。

## 我们如何使用

1. **先讨论，再动手。** 从原曲的特点、歌词、情感和演唱者出发，寻找这首歌自己的处理方式。
2. **把好听的原因说清楚。** 不只记录 Style，还记录前奏、间奏、尾奏、各段唱腔和情绪变化的设计。
3. **试听之后再记录结论。** 区分「设计意图」「用户听后确认的效果」与「还需实验的猜想」。
4. **跨歌曲复用审美经验，不复制编曲配方。** 不强制高音、强混、大鼓、特定乐器或统一参数。
5. **增量维护。** 新发现更新共识，新歌增加案例；保留旧结论和重要修订线索。
