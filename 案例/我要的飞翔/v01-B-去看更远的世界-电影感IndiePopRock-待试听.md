## 创作设计

这版不满足于把原曲加大鼓，而是把它设计成「从人海里走向旷野」的现代公路电影片尾曲。清音电吉他四音 Hook 贯穿前奏、间奏和尾奏；鼓、贝斯、人声共同由克制到开阔。最后一刻突然从宽阔空间变回一个人说话——「一起分享」才真正落地。

| 位置 | 人声与情绪 | 编曲与音乐任务 |
|---|---|---|
| 前奏 + Verse 1（原 LRC 00:00–00:35） | 温暖青年男声低中音区，结实、稍有犹豫；咬字自然 | 带短延迟的清音电吉他四音 Hook，闷音电吉他和微弱贝斯脉冲 |
| Pre-Chorus 1（00:35–00:59） | 语气更向前、逐渐开口，但不抢拍 | 底鼓、贝斯和钢琴脉冲加入，明确 Crescendo |
| Chorus 1（00:59–01:47） | Mezzo-forte 开放男声，不提前到最高声区 | 现场鼓、清亮电吉他、稳定低频，保持旋律可辨识 |
| 短间奏（01:47–02:02） | 无新增唱词 | 四音电吉他 Hook 变奏，再用短旋律回答 |
| Pre-Chorus 2（02:02–02:25） | 相同唱词改为更坚定的自我鼓励，胸声共鸣加强 | 贝斯更主动，通鼓渐进并制造第二遍副歌的期待 |
| Chorus 2（02:25–03:14） | Forte、明亮而有支撑的高位句子，按需要自然使用混声 | 双轨电吉他与完整现场鼓撑开声场，少量弦乐扩大纵深 |
| Final Refrain + Outro（03:14–结束） | 前三句成为全曲最后一次坚定表达；末句突然贴近听者 | 乐队达到峰值，末句前短暂 Stop-time；清音吉他独伴末句，尾奏回收 Hook |

这里的高潮不是单纯「越唱越高」。B 版最重要的对比是**前面把世界唱宽，最后把一个人唱近**；因此末句不再叠加乐队，而用短暂停顿与简洁吉他作为情感落点。

## 试听时最值得留意

- 清音电吉他四音动机能否在前奏、间奏、尾奏三次被听见、形成识别度。
- 第二次副歌能否比第一次明显展开，且人声不被层叠电吉他遮蔽。
- 最后一句前的短暂停顿是否自然，是否把高潮后的温柔留住，而非突然断裂。
