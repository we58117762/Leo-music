## 1. 反馈与修订边界

**Leo 对 v08 的实际反馈（2026-11-03）**：后半段「完全软下去了」，进一步确认是**人声和编曲两者都软**。此前 v07 已获得「很不错」的正向评价，尤其第一遍副歌的克制进入。

从文字对比可以看到，v08 相比 v07 去掉了部分明确的高声区、整队峰值与升调要求，又在第二副歌增加了“保留高音”的限制性措辞。这**可能**使后半段的力度目标不够清晰；由于尚未取得实际音频及账号当次设置，不能把该解释当作已验证因果关系。

**本轮只解决后段力度表达，不重新选曲风**：

- 保留徐佳莹《我是歌手》第四季第 4 期作为此前制作的参考版本，保留同一来源音频、同一 Voice、原有 37 行带声调拼音唱词的全文与重复顺序。
- 保留 v07 的第一副歌：青年男声以中音区、圆润连贯的唱法轻度展开，不把大高潮提前。
- 保留延迟电吉他与大提琴前奏主题、木吉他铺底、圆舞曲感器乐间奏、Bridge 的军鼓渐强以及最后吉他与独奏大提琴的器乐尾奏。
- 把 v08 的后半段抽象情绪词，改成**力度标记、明确唱法、声区、乐器层次与进入时机**。
- Style 保留共识规定的人声录音质感三词；Exclude 保持留空。参数首轮不变，以便比较**提示词调整**。

## 2. 依据：Suno 官方音乐术语的使用方式

参考 [Suno 官方 Music Glossary](https://help.suno.com/en/articles/9010177) 的术语与提示：段落用 Verse / Chorus / Bridge / Coda；演唱用 Legato / Belt / Vibrato；力度用 Crescendo / Forte / Fortissimo；编曲用具体乐器、Sparse / Dense 等。官方建议用力度变化塑造强度、用具体配器描述声音纹理。

**这些术语是官方建议尝试的词汇，不是 Suno 保证逐字执行的控制语言**。我们将它们组合成针对本歌的具体设计，不冒充“官方标准模板”。

对应的时间顺序：

| 段落 | 人声与力度 | 伴奏层次 | 与 v08 的区别 |
|---|---|---|---|
| Intro / Verse 1 | 中音区、受支撑胸声、Legato，较轻力度 | 延迟电吉他主题、独奏大提琴、稀疏钢琴与木吉他 | 保留原主题 |
| **Chorus 1** | **Mezzo-piano，温暖中音 Legato** | 轻鼓、贝斯、电吉他留白 | **保留 v07 已成功的克制展开** |
| Verse 2 | **Crescendo**，胸声逐渐增强 | 低音律动加强、弦乐加入、Toms 缓缓进入 | 更明确写出动态 |
| **Chorus 2** | **Mezzo-forte，向上发展的旋律乐句** | 鼓、贝斯、弦乐一起增密 | 删除“Save the Highest Belt”类延后约束 |
| 器乐圆舞曲间奏 | 无人声 | 吉他与大提琴对位、低音上行、Toms 与弦乐渐强 | 保留间奏身份，同时服务后半段峰值 |
| **Bridge** | **Forte，扎实胸声、上行乐句** | 军鼓渐强、弦乐增层、电吉他进入 | 不因桥段而突然变软 |
| 预高潮 | 无人声 | 军鼓滚奏渐强、弦乐上行、吉他八度、整队入场 | 明确形成可听到的推进 |
| **Chorus 3** | **明确高声区，Forte，Chest-Dominant Powerful Mixed Belt，持续高音** | 电吉他、鼓、密集弦乐同时推动 | 恢复 v07 对高音与强混声的具体要求 |
| 升调连接 | 上行一个全音的设计目标 | 上行和声与鼓填充 | 恢复明确请求，但不能保证模型精确执行 |
| **Final Chorus** | **Fortissimo，男高音强混、高音长音、自然颤音** | **全曲最大密度的现场乐队与弦乐** | 明确比第三副歌更大、更高、更持续 |
| Coda | 最后一句唱完，人声退出 | 乐队释放后电吉他主题与独奏大提琴再现 | 保留主题呼应 |

这里的 Forte / Fortissimo 不是要求全程大喊，而是在已经铺垫的后段明确设置音乐峰值。Style 中没有全局性的“温柔、克制、不得喊唱”禁令。

## 5. 本次变化的验证重点

- **先确认第一副歌没有退步**：依然是温暖的中音 Legato，尚未进入整首最高强度。
- **从第二副歌到 Bridge，声音和编曲是否同步积累**：声音共鸣更实、乐句上行，军鼓与弦乐真实变密。
- **第三与最终副歌是否终于站起来**：第三次明确高声区强混声，最终人声更有持续性，整队达到最高力度。
- **升调和旋律是否协调**：whole-step key change 是创作要求而非精准保证；若生成出现旋律错位或低调/变调问题，需依据实际音频再定位。
