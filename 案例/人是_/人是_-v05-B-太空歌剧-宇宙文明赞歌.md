## 1. 核心创意

**不是星际战斗配乐，而是宇宙文明的赞歌。**

这首歌要同时让人听到两种尺度：

- **近处的一个人**：青年男声温暖、扎实、带真实呼吸与情绪；即使宇宙再大，人声仍是整首歌的主体。
- **远处的文明**：交响乐、宽阔的宇宙合成器长音和遥远的**无词合唱**，像无数生命隔着星海回应主角。合唱只作氛围与和声，不单独演唱歌词，也不形成男女对唱。

**贯穿全曲的音乐身份**：

1. **钢琴信标**：前奏以孤独钢琴短动机像无线电信号般出现；间奏由合成器和法国号回应；尾奏在宏大声响消退后以更温暖的和声回归。具体音高与重复次数只是创作意图，Suno 不保证精确执行。
2. **两种空间**：近距离男声与巨大而遥远的交响/电子空间形成反差；空间效果主要交给乐器和无词合唱，人声保持清晰、凝聚。
3. **从个人到文明**：第一遍副歌是一人的选择，第二遍增加管弦与合唱的回应，最终副歌让文明的宏大声音托举主唱的高音，而不掩盖他。

**Leo 的两条核心要求**：

- 喜欢《人是_》原曲的**高音**：保留最高旋律区的声乐冲击，最终副歌必须有支撑、厚度和明亮穿透力，不把「空灵」理解成轻飘的人声。
- **Bridge 绝不能软下来**：电子脉冲、低弦乐律动、定音鼓与声乐投入持续向前；允许乐器层次改变，但不出现突然的情绪泄气或轻声倾诉式重置。

Space Opera 在这里指**宏大的科幻音乐叙事**，不意味着把男声改成舞台歌剧的美声唱腔；主唱仍是自然、有力量的现代青年男声。

## 2. 分段音乐设计

| 段落 | 人声与情绪 | 交响、合唱与宇宙音色 |
|---|---|---|
| Intro | 无人声，先建立孤独和浩瀚 | 深沉模拟合成器长音、遥远无词合唱、钢琴信标动机、大提琴与悬浮弦乐 |
| Verse 1 / Pre-Chorus 1 | 单一男声近距离叙述，清晰扎实；随后逐渐坚定 | 钢琴和大提琴衬托个人，低频电子脉冲和低弦乐开始出现 |
| Chorus 1 | 第一次有力量地打开旋律，但留住后续高音空间 | 弦乐展开，法国号如远方回声，合唱仍然遥远、无词 |
| Interlude | 无人声，形成科幻辨识度 | 钢琴信标由合成器与法国号接力，弦乐发展成新的上行回应 |
| Verse 2 / Pre-Chorus 2 | 更紧迫、更主动的胸声表达 | 低弦乐固定音型、电子脉冲与鼓持续加压，合唱从远处逐渐靠近 |
| Chorus 2 | 更强的胸声主导混声、饱满共鸣与明亮高音 | 铜管、定音鼓、全弦乐加入；无词合唱作为背景托举而不抢人声 |
| **Bridge** | **持续有力的男声，字头明确、乐句向前、音色不虚；情绪只积累，不突然软下来** | **低弦乐与定音鼓保持连续律动，电子脉冲不停止，合唱与和声不断积聚张力** |
| Instrumental Build | 无歌词，短暂吸气后进入终章 | 法国号/铜管上行，定音鼓滚奏，合唱扩展，信标主题嵌入交响 |
| Final Chorus | **全曲最有穿透力的高音混声，悲壮、坚定、带希望；男声始终在前** | 宏大交响与宽阔无词合唱到达顶点，电子宇宙声场扩大但不压盖主唱 |
| Final Peak / Outro | 最后一句完整唱完，长音自然收束 | 管弦和合唱在最后一字后散开；孤独钢琴信标以温暖和声回归，宇宙渐渐安静 |

**Style 长度**：995 字符（包括固定人声录音质感提示词）。

提示词中的「无词合唱」是**背景音乐层次**，不是另一位主唱或新增歌词。这里是全新编曲探索，因此在完整 Style 末尾追加当前共识中的 `Dry Professional Studio Vocal, No Reverb, 48kHz.`，不是采用「旧成片只做录音质感精修」的独立三词方案。

## 4. 首轮建议参数

**为了比较「电影感管弦深化」和「太空歌剧文明赞歌」两种音乐设计，首轮建议与 v04 保持同一组参数。** 这样能够更集中地听出曲风、配器和唱法设计的差异。以下均为建议起点，不冒充历史实测值。

## 5. 试听时最值得注意的四个地方

1. **宇宙感是否有辨识度**：钢琴信标、模拟合成器长音、法国号和遥远无词合唱是否真的营造了巨大的空间，而不是普通的电影预告片式配器堆叠？
2. **合唱是否摆对位置**：有没有形成「文明回应」的感觉？是否仍然清楚听见单一青年男声主唱，而不是被合唱团接管歌词？
3. **Bridge 是否一路顶住**：人声有没有保持投射力、低弦乐和鼓是否持续推进？不应出现突然变轻、虚声或演唱投入下降。
4. **最终高音是否有感染力**：高音要高亢、扎实、明亮，也要有人类在绝境中仍然选择前进的情感，而不只是更响的声压。

这些是创作目标，并非已经听到的实际结果。满意可以直接继续创作；若有偏差，再根据具体试听问题定向调整。
